# EVUnify — Roadmap

## Phase 0 — Research & Concept (Complete — Oct 2026)
- Market research on OEMs and CPOs.
- Pain point validation.
- Concept and architecture outline.

## Phase 1 — MVP (Target: 4–6 weeks)
- Seed database with public sources + 2–3 partner networks.
- Basic mobile map with filters and station details.
- Google Maps “open in” and contribution flow.
- User accounts and favorites.
- Simple admin for verification.

## Phase 2 — Live Data & Partnerships (Target: 2–3 months)
- Integrate OCPI or APIs with 5+ major networks (Tata Power, Statiq, ChargeZone, MG e-Hub data, etc.).
- Real-time status for partnered stations.
- Route planning with charging stops.
- User reviews and reports.
- Partnership outreach playbook.

## Phase 3 — Scale & Polish (Target: 4–6 months)
- Broader network coverage.
- Unified payment options where feasible.
- Fleet / B2B features.
- Advanced analytics and reliability scoring.
- Full Google Maps data feed partnership exploration.

## Ongoing
- Monitor government Unified Bharat e-Charge progress.
- Continuously improve data quality and de-duplication.
- User feedback loops.

## Immediate Next Actions
1. Create GitHub issues for MVP tasks.
2. Outreach list for top CPOs/OEMs.
3. Prototype map UI.
4. Legal review of data usage.
