# EVUnify — Product Concept

## Vision
One neutral platform where every EV driver in India can discover, filter, navigate to, and trust charging stations from all OEMs and CPOs — with full visibility on Google Maps.

## Core Principles
- **Neutral**: Not owned by any single OEM or CPO.
- **Respectful**: Deep-links or redirects to original operator apps for session start and payment.
- **Maps-first**: Stations become visible and usable in Google Maps navigation.
- **Reliable**: Prioritize accurate, up-to-date data (real-time where possible).
- **Open where possible**: Prefer OCPI and public standards over scraping.

## Key Features (MVP → Full)
1. Unified interactive map of all aggregated stations.
2. Filters: network/OEM, connector (CCS2 primary), power, availability, price, amenities.
3. Vehicle profile for compatibility matching.
4. Route planner with optimal charging stops.
5. Real-time or near-real-time status (partner-dependent).
6. Station details, photos, user reviews, “report issue”.
7. Navigation + deep link to operator app + “Open in Google Maps”.
8. Favorites, history, notifications.
9. User contributions and verification.
10. Later: unified payments/wallet options, booking, fleet tools.

## Differentiation
- Strong focus on Google Maps visibility and contribution.
- Neutral positioning (complements rather than competes with OEM apps).
- Emphasis on data quality and real-time reliability.
- Clean UX that reduces app-switching for discovery and navigation.

## Monetization Options
- Session commissions (if initiating charges).
- Premium features (advanced planning, alerts).
- B2B / fleet dashboards.
- Data insights.
- White-label for partners.

## Success Metrics
- Station coverage completeness.
- Real-time accuracy rate.
- User sessions and retention.
- Percentage of stations visible on Google Maps.
- Partnerships secured.
